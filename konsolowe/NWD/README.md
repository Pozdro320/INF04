# Algorytm Euklidesa (NWD)
Aplikacja konsolowa napisana w języku C#, obliczająca największy wspólny dzielnik dwóch liczb całkowitych dodatnich za pomocą algorytmu Euklidesa.

## Działanie programu
Program główny pobiera od użytkownika dwie liczby całkowite dodatnie `a` oraz `b` i kontroluje poprawność wprowadzonych danych. Następnie przekazuje je jako argumenty do dedykowanej funkcji, która bez operacji wejścia-wyjścia oblicza wynik metodą odejmowania zgodnie ze schematem blokowym.
