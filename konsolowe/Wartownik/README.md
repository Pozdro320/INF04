# Przeszukiwanie tablicy z wartownikiem

Aplikacja konsolowa napisana w języku C#, realizująca algorytm przeszukiwania tablicy z wartownikiem

## Działanie programu
Program wypełnia 50-elementową tablicę liczbami pseudolosowymi z zakresu od 1 do 100 za pomocą dedykowanej metody Następnie pobiera z klawiatury szukaną wartość i umieszcza ją jako wartownika na końcu tablicy (pod kolejnym indeksem), co zabezpiecza algorytm przed wyjściem poza jej zakres

Osobna metoda przeszukuje tablicę do momentu napotkania szukanej liczby i zwraca jej indeks Na koniec program wyświetla w konsoli wszystkie wylosowane elementy tablicy oddzielone przecinkami oraz podaje indeks pierwszego wystąpienia szukanej wartości lub informuje o jej braku w tablicy
