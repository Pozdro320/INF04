# Sortowanie przez wybieranie

Aplikacja konsolowa napisana w języku C#, realizująca sortowanie tablicy metodą przez wybieranie.

## Działanie programu
Program pobiera z klawiatury 10 liczb całkowitych i zapisuje je w tablicy będącej polem klasy. Następnie sortuje je malejąco (od największej do najmniejszej) bez użycia gotowych funkcji bibliotecznych.

Algorytm w każdym kroku wyszukuje najwyższą wartość w nieposortowanej części tablicy za pomocą prywatnej metody, a następnie zamienia ją miejscami z elementem na bieżącej pozycji. Na koniec program wyświetla wszystkie elementy posortowanej tablicy na ekranie konsoli.
