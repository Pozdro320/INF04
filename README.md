# INF.04 – Rozwiązania zadań egzaminacyjnych

Repozytorium zawiera rozwiązania zadań praktycznych z egzaminu zawodowego w kwalifikacji **INF.04** (*Projektowanie, programowanie i testowanie aplikacji*).

## Struktura repozytorium

Projekty zostały podzielone na cztery główne kategorie odpowiadające częściom praktycznym arkuszy egzaminacyjnych:

* **`konsolowe/`** – aplikacje konsolowe oraz programowanie obiektowe.
* **`desktopowe/`** – aplikacje okienkowe z graficznym interfejsem użytkownika.
* **`mobilne/`** – aplikacje mobilne tworzone na platformy przenośne.
* **`webowe/`** – aplikacje internetowe.

## Zawartość każdego zadania

Każdy podfolder z konkretnym zadaniem zawiera:
* kod źródłowy rozwiązania z komentarzami,
* krótki plik `README.md` z opisem działania programu zgodnym z wymaganiami arkusza.

## Technologie
* **C#** (.NET Framework / WPF / .NET MAUI)
* **HTML / CSS / JavaScript / React / Bootstrap** (aplikacje webowe)
